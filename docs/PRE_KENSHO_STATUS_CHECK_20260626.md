## A. コンテンツ幅・レイアウトのずれ（#1）

### 調査結果
| 確認項目 | 値・状態 |
|---|---|
| SWELLサイト幅（`--container_size`） | **1200px**（HTMLに出力。`.l-container{margin:auto; max-width:1200px+余白}` ＝**中央寄せ**） |
| SWELLカスタマイザー設定 | **theme_mods_swell_child は実質空**（`nav_menu_locations`空・`custom_css_post_id:-1` のみ）。`theme_mods_swell` も空 ＝ **未カスタマイズ＝すべて既定値** |
| 子テーマ `style.css` | **中身は空**（ヘッダーコメントのみ。レイアウトCSSなし） |
| 子テーマ `functions.php` | style.css を読み込むのみ（幅・マージン指定なし） |
| Code Snippets | CSS/幅を出力するスニペットは**なし**（id5〜8はCF7検証・テストSMTP・mailtoリンク・サイトマップで、表示幅に無関係） |
| 追加CSS（カスタマイザー） | swell_child は `custom_css_post_id:-1` ＝**なし** |
| レイアウト | body クラスに **`-sidebar-on`**（本文＋サイドバーの2カラム） |
| サイドバーウィジェット | `sidebar-1` = **空**（`a:0:{}`。全SWELLウィジェット枠が空） |

### 判定：🎨 デザイン未調整（設定ミス・CSS不具合ではない）
- **幅やマージンを狭めるCSS・設定は存在しない。** コンテナは1200pxで中央寄せの正常値。
- 「狭く左寄り」に見える正体は、**SWELL既定の2カラム（本文＋サイドバー）で、サイドバーが空**のため、本文が左の主カラム（コンテナの約7割）に収まり、右のサイドバー領域が空白になっていること。全ページが同じ2カラム既定なので、**全ページで同様**に見える。
- これは「設定ミス」ではなく「**デザイン未調整の標準状態**」。デザイン方針確定後に、①1カラム/2カラムの選択、②コンテンツ幅、③サイドバーの内容（または非表示）、を整えれば解消する。

## B. ヘッダー・ナビゲーション（#2, #3）

### B-1. ナビにフォーム完了ページが出る（#2）

#### 調査結果
- **SWELLのメニュー位置（nav_menu_locations）は未割り当て**：`theme_mods_swell_child` の `nav_menu_locations` = **空 `a:0:{}`**。
  - 旧テーマ（TCD NANO）では `global=14`（グローバルメニュー）・`footer=15` が割り当て済みだった。**テーマ切替時にメニュー位置の割り当てが引き継がれていない。**
- メニュー位置が空のため、SWELLヘッダーは**公開ページを自動列挙するフォールバック表示**になっている（`menu-item` クラス付きで描画されるが、中身は「メニュー」ではなく「公開ページ一覧」）。
- 列挙される中に、**MW WP Form 時代の残存ページ**が含まれる：

| ページID | タイトル | 種別 | 備考 |
|---:|---|---|---|
| 560 | お問い合わせを承りました | page/publish | 旧フォーム完了画面の実ページ |
| 559 | お問い合わせ内容のご確認 | page/publish | 旧フォーム確認画面の実ページ |
| 546 | 個別説明会の申込を承りました | page/publish | 旧フォーム完了画面の実ページ |

- これらが**自動列挙でナビに表示**されている（＝大野様が見た項目）。

#### 本来あるべきナビ（本番の構成・ステージング内にも正しく存在）
正規の「**グローバルメニュー**」（term_id=14, 23項目）は**内容が正しく**、完了/確認ページは**含まれていない**。本番（pegasus-job.com・閲覧のみ）でも同じ構成で、**完了/確認ページはナビに出ていない**ことを確認済み。

| 階層 | 項目（リンク先） |
|---|---|
| HOME | / |
| 就労サポート | 充実したプログラム / 就職前に企業実習 / 就職活動サポート / 就職後も安心のアフターケア / 利用者の声 / 就労決定者の声 / 在宅型就労移行支援サービス |
| ペガサスとは | 法人概要 / アクセス / スタッフ求人情報 / プライバシーポリシー / ご利用案内 |
| コラム/ブログ | 代表コラム / スタッフブログ / 同窓会 |
| 個別説明会申し込み・お問い合わせ | 個別説明会申し込み(151) / お問い合わせ(155) / 資料請求(157) |

#### 判定：⚙️ 設定の配線抜け（要修正・低リスク）
- 原因は**メニュー位置の未割り当て**。SWELL「外観 → メニュー → メニューの位置」で、**グローバルメニュー(14) をヘッダーに、フッターメニュー(15) をフッターに割り当て直す**だけで、フォールバックの自動列挙が止まり、正規メニューに戻る（完了/確認ページは消える）。
- 残存ページ（546/559/560）は MW WP Form 時代の遺物で、現在はCF7＋301転送に置き換え済みのため、**メニュー修正後に noindex/除外 もしくは削除（Phase 4整理）**で対応可。
- **これは「今直してもよい設定」**（メニュー位置の割り当ては低リスク）。ただしヘッダーの体裁はデザインにも関わるため、デザイン調整とまとめて実施してもよい。**本調査では未修正**（ご判断待ち）。

### B-2. ロゴの改行（#3）
- 調査結果：**custom_logo（ロゴ画像）が未設定**（swell_child / swell / 旧テーマいずれの theme_mod にも custom_logo なし）。
  - 旧TCD NANOはテーマ独自のロゴ設定欄に画像を持っていた（custom_logo ではない）ため、**SWELLにロゴ画像が引き継がれていない**。
- 現状はロゴ枠に**サイト名テキスト「一般社団法人ペガサス」**が表示され、枠幅で**折り返し**ている。
- 判定：🎨 **デザイン未調整**。デザイン方針確定後、SWELL「サイト基本情報 → ロゴ」に**ロゴ画像を設定**すれば改行は解消。

## E. 「デザイン刷新で整える部分」と「今直すべき設定」の切り分け

### 🎨 デザイン刷新で整える部分（想定内・今は触らない）
- コンテンツ幅／2カラム・サイドバー（#1）
- ロゴ画像の設定（#3）
- メインビジュアル／キャッチコピー（#4）
- デザイン直結ブロック系プラグインの整理（gutentor 等）

### ⚙️ 今直してもよい設定（低リスク・任意。デザイン待ちでも対応可）
- **メニュー位置の割り当て（#2）**：グローバルメニュー(14)→ヘッダー、フッターメニュー(15)→フッター。
  - 効果：ナビが正規構成に戻り、フォーム完了/確認ページが消える＝**検収時の誤解を防げる**。
  - リスク：低（既存メニューを位置に割り当てるだけ。投稿・データ無変更）。
  - ※ ヘッダー体裁はデザインにも関わるため、**デザイン調整とまとめて実施**でも可。本調査では未実施（ご判断待ち）。
- （付随）残存フォームページ 546/559/560 の noindex/除外 or 削除（Phase 4整理）。

> **明確な「不具合・壊れ」は無し。** 設定ミスに該当するのは「メニュー位置の未割り当て」1点のみで、これも投稿データやレイアウトを壊すものではなく、割り当てるだけで解消する軽微なもの。
