## 1. 本書の位置づけ

本書は、5月29日にペガサス様へ提出済みの **「URL検証・リダイレクト計画表（骨組み版）」を発展させた完成版** です。
**新規の方針策定ではなく、既に合意済みの方針を維持したまま、不規則URL 4系統（計100件）の具体的な投稿リストを実データから抽出して詳細化** したものです。

骨組み版で確定済みの方針（変更なし）:

- 現行サイトの **公開URLは原則すべて維持**（SEO資産の保全）
- URLの変更は **必要最小限（タイポ修正のみ）** に留め、すべて **301リダイレクト** で対応
- リダイレクトは **3項目のみ**（下記）

| 旧URL（誤） | 新URL（正） | 影響範囲 | 実装時期 |
|---|---|---|---|
| /user-dicision1/ | /user-decision1/ | 投稿1件 | Phase 5 |
| /category/user-dicision/ | /category/user-decision/ | カテゴリー＋配下10件 | Phase 5 |
| /news_category/infomation/ | /news_category/information/ | カテゴリー＋配下32件 | Phase 5 |

## 2. 今回詳細化した内容（追加点）

骨組み版では「全体規模（公開済み）」として件数のみを示していた箇所のうち、**ルート直下に配置された不規則URL 4系統** について、ステージング環境のデータベース（本番の完全コピー）から **公開状態（post_status=publish）の投稿を1件ずつ抽出** し、旧URL→新URLの対応表を作成しました。

### 抽出条件
- 投稿タイプ: `post`（通常投稿）
- 公開状態: `publish`
- スラッグ: `blog%` / `user-voice%` / `user-decision%`・`user-dicision%` / `reunion%`

## 4. Redirection プラグイン用インポートCSV

`url_redirects.csv` を同梱しました。Redirection プラグインの「Import/Export」画面からそのままインポートできます（列: source, target, regex, code）。

```csv
source,target,regex,code
/user-dicision1/,/user-decision1/,0,301
/category/user-dicision/,/category/user-decision/,0,301
/news_category/infomation/,/news_category/information/,0,301
```

- **1行目** が本書スコープ（4系統）から確定したリダイレクトです。
- **2〜3行目** は骨組み版②で既に確定済みのカテゴリー綴り修正を、そのまま（変更せず）同梱したものです。実際の実装時に3件まとめてインポートできるよう、完全な形にしてあります。
- **維持URL（99件）はCSVに含めません。** 同一URLへの自己リダイレクトは不要（かつ有害）なため、実際に転送が必要な行のみを記載しています。

### 実装時の注意（骨組み版②より継承）
- カテゴリースラッグ変更時は、WP管理画面でスラッグを書き換えた後、旧スラッグからのリダイレクトを追加する（WordPressは自動でリダイレクトを生成しないため要注意）。

- Search Console で旧URLのインデックス削除と新URLの登録を促す。
