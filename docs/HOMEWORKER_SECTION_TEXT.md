## 3. /homeworker/ 主要文言（在宅紹介の要約・誘導に使える中核）

> ステージングの最新版（page ID 1067）から抽出。本文が非常に豊富なため、**トップの要約に使える中核**を優先的に整理。全文はページ参照。

### リード（冒頭・要約に最適）
- **ご自宅で「働くための訓練」を行い在宅勤務という目標を応援します。あなたらしい働き方で「働きたい」という気持ちを私たちが支えます。**
- 最近では働き方の多様化が進む中、自分らしく働くスタイルのひとつとして在宅勤務を積極的に検討されている方もいらっしゃることでしょう。このページをご覧になっているすべての方の「働きたい」をペガサスは大切に考えています。

### 「在宅型 就労移行支援」とは?（Q&A）
- **質問:** ペガサスの「在宅型 就労移行支援」とは?
- **答え:** これまでの実績を活かし、ご自宅で「在宅勤務」を目指せるサービスです。
- ストーリー要約：私たちは通所型で多くの就職を支えてきた → しかし「働きたいけど通うのが難しい」方が多いと分かった → **そこで2022年から、ご自宅で訓練から就職までを目指せる「在宅型」サービスを開始**。通所型で培った経験＋在宅ならではのサポートで就職を支える。

### 『ペガサス』ならではの支援と強み（4つ）
- **強み①：本番の仕事を想定した訓練**（訓練自体が本物の在宅ワーク体験。クラウド/タスク管理/報告/チャット/オンライン会議。安心して失敗できる環境）
- **強み②：提携企業で「おためし就職」ができる**（企業実習で「自分も働ける」自信・適性把握・入社後のミスマッチ防止。※斡旋はしないが実習から就職例あり）
- **強み③：スタッフとの関わり**（月1回 対面面談〈通所困難なら自宅訪問〉／週1回 ZOOM／毎日 電話・チャット）
- **強み④：充実した訓練プログラム**（ビジネス／メンタル／パソコン。ZOOMで在宅からリアルタイム受講、カメラオフOK）

### こんなお悩み → こう変われます（共感→解決・CVに有効）
- お悩み例：人混みや体のことで外に出るのがむずかしい／生活リズムが不規則だけど訓練を続けられるか心配／パソコンは初心者。自分にできる仕事はある?／就活のやり方やオンライン面接がよく分からない
- **ペガサスの支援で、こう変われます!**：完全在宅で自分のペースで時間・日数を決められる／スタッフと話す中で自然とコミュニケーション力が上がる／PCの基礎から学べ模擬面接など就活も手厚くサポート／会社に必要な配慮を伝え能力を発揮できる／就職後も卒業後もスタッフに相談できる

### 3ステージ（訓練→就活→定着）
- **ステージ①：就労準備期（土台づくり）** … セルフケア＋訓練プログラム（eラーニング／外部講師講座〈ZOOM〉／実務訓練〈データ入力・請求書作成・日報集計〉／PC学習）
- **ステージ②：就活準備期〜就活期** … STEP1 求人条件理解・自己理解／STEP2 自分に合う仕事探し／STEP3 応募書類作成（添削）／STEP4 模擬面接（オンライン注意点も）
- **ステージ③：就職してからもサポート（就労定着支援）** … 月1面談で悩み・要望をヒアリング、必要なら会社と調整

### 対象・期間・料金（信頼/条件の明示）
- **対象:** ①障害者手帳をお持ち、または②医師から障害の診断（発達障害・精神障害・身体障害など）。かつ 18歳〜65歳未満で、パソコンを使った在宅での仕事をしたい／事業所に通うのは難しいが家なら訓練できそう、という方。
- **利用期間:** 最大2年間（就職が決まればいつでも卒業）。
- **利用料:** **9割以上の方が無料で利用**（国の福祉サービスのため前年収入等で決定）。
- **エリア:** **全国対応**（月1回の面談はスタッフが自宅近くまで訪問。交通が難しい地域は要相談）。

## 5. CV再設計への申し送り
- **主役化:** 在宅バナー（自宅で訓練!/自宅で働く!）＋4動画＋ `/homeworker/` の強み4点を、トップの**在宅紹介セクション**に集約し、`/homeworker/` へ誘導。
- **要約の核:** 「これまでの通所実績を活かし、**2022年から在宅型を開始**」「**完全在宅**で訓練〜就職〜定着まで」「**全国対応**」「**9割以上が無料**」「月1訪問・週1 ZOOM・毎日電話の**手厚いサポート**」。
- **共感導線:** 「人混み/体調で外出が難しい」「通勤がつらい」→「完全在宅で自分のペースで」。
- **画像:** 実写は 27186561（在宅ZOOM受講）が最有力。フロー図（2025/07）は「ご利用の流れ」に流用可。図解バナー（img_homeworker系）は情報が古い/文字焼き込みのため、リデザインでは**再構成推奨**。
- 動画4本はそのまま活用可（URLは§2）。
