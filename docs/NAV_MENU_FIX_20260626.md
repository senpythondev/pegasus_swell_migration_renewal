## 3. メニュー位置の割り当て

WordPress標準API `set_theme_mod('nav_menu_locations', …)` で安全に更新（シリアライズはWPが処理）。

| メニュー位置 | 割り当てたメニュー |
|---|---|
| `header_menu`（PCグローバルナビ） | **14 グローバルメニュー** |
| `nav_sp_menu`（スマホ開閉メニュー内） | **14 グローバルメニュー** ※ |
| `footer_menu`（フッター） | **15 フッターメニュー**（現状0項目＝空） |

> ※ **`nav_sp_menu`（SPドロワー）も 14 を割り当て**た理由：SP側も未割り当てだと同じ「公開ページ自動列挙」フォールバックでフォーム完了ページが出るため。PC・SP両方を正規メニューに揃え、ナビ正規化を完結させた。メニューの内容は変更していない（同じ term14 を参照させただけ）。
> footer_menu は term15 が空のため表示項目は無し（従来どおり）。フッターの内容整備はデザイン工程で別途。

設定後の `nav_menu_locations`：
```
header_menu => 14
nav_sp_menu => 14
footer_menu => 15
```
