## 3. CF7 移行 設計メモ

### 3-1. 項目マッピング（CF7 フォームタグ）
**お問い合わせ（1352）**
```
[text* your-name]            … お名前（必須）
[text kana]                  … ふりがな（任意）
[email* your-email]          … メールアドレス（必須）
[email* your-email-confirm]  … メールアドレス（確認・必須・一致検証は §3-3）
[textarea* your-message]     … お問い合わせ内容（必須）
[submit "送信内容を確認する"]
```
**個別説明会申込（1369）**
```
[radio address use_label_element "平塚事業所" "在宅訓練"]  … 希望会場（必須化を推奨）
[text* your-name] / [text kana]
[email* your-email] / [email* your-email-confirm]
[textarea your-message]      … 備考（任意）
[submit]
```

### 3-2. メール設定マッピング
| MW WP Form | CF7 |
|---|---|
| 管理者通知メール | **Mail**（1通目）。宛先=各フォームの管理アドレス、件名・本文を移植 |
| 自動返信メール | **Mail (2)**（2通目）を有効化。宛先=[your-email]、差出人名=事務局/説明会担当 |
| 差出人 From `{E-mail}` | CF7 では **From をサイトドメインのアドレス**にし、**Reply-To に [your-email]** を設定（なりすまし扱い/SPF・DKIM失敗を避けるため。MWの挙動をそのまま移すと迷惑メール判定の恐れ） |
| 件名の `{your-name}` | CF7 メールタグ `[your-name]` に置換 |

- 送信先（宛先）: お問い合わせ=`info@[managed-domain]` ／ 個別説明会=`setsumei-kai@[managed-domain]`

### 3-3. 確認画面・完了画面の扱い（最重要・要方針決定）
- MW WP Form は **入力→確認→完了の3ページ遷移**（/contact/、/contact/contact-confirm/、/contact/contact-thanks/ など、いずれも公開URL）。
- **CF7 は標準で確認画面を持たず**、同一ページ内のAJAX送信＋インライン完了メッセージが基本。
- 選択肢:
  1. **確認画面なしに簡素化（推奨・最小工数）** … 入力ページ1枚に集約。/contact-confirm/、/contact-thanks/、/application/confirm/、/application/thanks/（公開4URL）は不要化 → **301リダイレクトで /contact/、/application/ へ寄せる**（URL資産は転送で保全）。
  2. **確認画面を維持** … アドオン（例: Contact Form 7 Multi-Step Forms 等）で確認ステップを再現。工数増・保守対象増。
- いずれにせよ、既存の確認/完了ページ4枚の去就を決める必要があります（提案書のURL維持方針に直結）。

### 3-4. 送信データの保存（usedb=1 の代替）
- MW WP Form は送信内容をDB保存（管理画面で閲覧可）。**CF7は標準で保存しません。**
- 対策: **Flamingo プラグイン**（CF7作者製・無料）を導入すれば送信内容を保存・一覧可能。問い合わせ履歴を管理画面で見たい場合は必須。

### 3-5. メールアドレス確認欄（E-mail2）
- 「確認のため再入力」を CF7 標準機能では一致検証できません。
- 対策: **Code Snippets（導入済み）** に `wpcf7_validate_email*` フィルタの一致チェックを追加、または該当アドオン。数行で実装可能。

## 4. 移行時の注意点・リスク（まとめ）

| # | 項目 | 内容 | 対応 |
|---|---|---|---|
| 1 | 確認/完了ページ | MWは実URL3ページ。CF7はインライン。公開4URLの去就 | §3-3で方針決定（推奨: 簡素化＋301転送） |
| 2 | 送信データ保存 | usedb=1 をCF7は再現しない | Flamingo 導入 |
| 3 | メール確認欄一致 | E-mail2==E-mail の検証 | Code Snippets で検証追加 |
| 4 | 差出人From | `{E-mail}` を From にすると迷惑メール化の恐れ | From=サイトドメイン、Reply-To=入力アドレス |
| 5 | 1369の残骸 | phoneバリデーション残存・address未必須 | CF7移行時に整理（phone廃止、address必須化を確認） |
| 6 | 宛先の正確性 | 説明会は `setsumei-kai@`、問い合わせは `info@` と宛先が異なる | フォームごとに宛先を取り違えない |
| 7 | スパム対策 | MWのAkismet項目相当 | CF7でAkismet/reCAPTCHA有効化を推奨 |
| 8 | 資料請求 | MWではなくDownload After Email（停止中） | CF7化するか・別運用か、別途方針確認 |
| 9 | 旧フォーム3件 | 536/555/1135 は未使用 | 移行後に整理（削除候補） |

## 5. 次のステップ（移行本番）に向けて
1. §3-3 の確認/完了画面の方針をペガサス様と決定（推奨: 簡素化＋301転送）。

3. Flamingo 導入（送信保存）、Code Snippets でメール確認欄の一致検証を追加。
4. /contact/、/application/ にCF7を配置 → 送信テスト（管理通知・自動返信の受信、宛先の正誤）。
5. 旧 MW WP Form（5件）と確認/完了ページの整理。
