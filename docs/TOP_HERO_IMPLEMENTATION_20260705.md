## 1. 実装したFVの内容（実装計画書§3どおり）

- **メインコピー（H1）:** しあわせに働くために、生きている。
- **サブコピー（eyebrow）:** 在宅で、自分のペースで。
- **ディスクリプション:** 「人が怖い」「通勤がつらい」方のための、在宅型就労移行支援。
- **背景:** 低刺激の淡い青グラデーション（`#eef5fe → #dcebfc → #cbe0fb`、`--pega-base` を基調にした淡色）＋濃色テキスト。深夜モバイルでもまぶしくないトーン。
- **2段階CTA:**
  - プライマリ「在宅型を詳しく見る ＞」→ `/homeworker/`（**緑 `--pega-accent`**・濃色文字でAA確保）
  - セカンダリ「個別説明会に申し込む（無料）→」→ `/application/`（**ブランド青 `--pega-base`**・白文字）
- **信頼指標バー（FV直下・2指標）:** 「10年以上／精神・発達障害に特化した創業実績」・「100名以上／就職実績」。※継続率は今回入れない（指示どおり）。
- **レスポンシブ:** PCは2カラム（左コピー／右画像）、SPは縦積み（画像を上・コピー＆全幅CTA下）。CTAは`min-height:60px`＋SP全幅で大きなタップ領域。`overflow:hidden`で横スクロール防止。

### 文言の統合について
実装計画書の設計文言をそのまま採用（現サイトの理念「しあわせに働くために生きている」を圧縮したメインコピーは現文言と整合）。在宅特化・CV向上の方向性を維持。

## 2. 選定したFV画像 ⚠️二重チェック報告

- **選定:** 添付ID **3958**「A woman who communicates online using a tablet PC」
  - ファイル: `wp-content/uploads/2024/04/0e50f63b88743c28c377d6590d27b19c.jpg`
  - 解像度: **612 × 408 px**（28KB）
  - 絵柄: 自宅ダイニングでタブレットを見ながらノートに書き込み、**笑顔で在宅ワークをする女性**＝計画書のFV画像要件（自宅で穏やかにPC作業する人物・柔和・ナチュラル）に合致。
- **指示との差分（報告）:** 指示は「img_homeworker 系から選定」でしたが、**img_homeworker1〜5 は実写ではなく図解インフォグラフィック**（例: 熊のイラスト＋吹き出しの「テレワーク雇用直結プログラム」図）でした。`mv_sp.png`は旧ブランドの空画像（旧文言埋め込み）、`在宅訓練`(ID3612)はオンライン面談のイラスト。**「在宅で穏やかにPC作業する人物」の実写は ID3958 が唯一の適合**だったため、これを採用しました（指示の「適切なものがなければ最も近いもので暫定実装し報告」に沿う）。
- **解像度の扱い:** 612pxと小さめのため、**フルブリードにせず contained レイアウト（表示幅〜560px・原寸内）**で使用し、ぼやけを回避。より大きく使う場合は**高解像度版の用意を推奨**（フリー素材差し替え or 友本様支給）。

## 3. トップページの設定

- 固定ページ「ホーム」(ID=4865, slug=`home`) を新規作成、`post_content` にヒーローのブロック（`scripts/top_page/hero.html`）を格納。
- `show_on_front` = `page` / `page_on_front` = 4865（旧: `posts`＝投稿一覧）。
- `page_for_posts` は未設定のまま（標準ブログは個別URL・アーカイブで存続。CPTの news/reports/column は無影響）。
- **SWELL設定（`loos_customizer`）:**
  - `show_sidebar_top` = **false**（トップをサイドバー無し＝全幅化）。
  - `main_visual_type` = **none**（既定メインビジュアル「さぁ、始めよう。」＋緑豆画像を無効化）。
  - `show_post_slide` = **''**（トップの投稿スライダー＝ブログカルーセルを無効化）。
- **フロントのページタイトル帯**は `.home #top_title_area{display:none}` で保険的に非表示（SWELLは静的フロントで元々未出力）。

> これらの設定変更は**トップページのみ**に作用し、他ページ・既存機能には影響しません。

## 4. 技術・成果物

- **ブロック:** `<!-- wp:group align:full -->` ＋ `<!-- wp:html -->`（クリーンなセマンティックHTML／class のみ、inline style・script なし＝KSESで壊れない）。ソースは `scripts/top_page/hero.html`（版管理・本番再現用）。
- **CSS:** 子テーマ `swell_child/style.css` に追記（`.pega-hero` 一式）。色は `var(--pega-*)`。明るい背景の小さめ文字用に、**ベース青の濃いシェード `--pega-base-ink:#0a4aa8`**（友本様3色からの濃淡・ブリーフィングで許容）をAA確保のために定義。
- **アクセシビリティ:** コントラスト比 AA以上（H1濃紺 on 淡青 ≒10:1／緑ボタン＋濃色文字 ≒7.6:1／青ボタン＋白 ≒5:1）。`alt`付与、`:focus-visible`アウトライン、`aria-label`。

- URL: `http://220.158.21.114:8080/`（Basic認証。ユーザー `pegasus` ＋ 別途共有のパスワード）

```bash

  --window-size=1440,1300 --virtual-time-budget=8000 \
```

## 6. ⚠️ 二重チェック（実装前・実装中に確認/判断した点）

1. **FV画像:** 指示の img_homeworker 系は図解のため、被写体が合致する実写 ID3958 を採用（§2）。高解像度版は要検討。
2. **CTAの色（緑の使い分け）:** ブリーフィング§5は「申込＝緑」ですが、今回のFV指示は「**プライマリ（在宅型を詳しく見る）＝緑**」。指示を優先し、プライマリを緑、申込セカンダリをブランド青にしました。`--pega-accent`は明度が高く白文字がAA不足のため、緑ボタンは**濃色文字**でAA確保。用途別配色の最終確定時に入れ替え容易（要・司令塔/友本様確認）。
3. **青系の濃淡:** 小さめ文字のAAのため、ベース青の濃いシェード `--pega-base-ink` を定義（ブリーフィング「#1067D6基準に濃淡可」に沿う）。
4. **背景の青:** 「濃すぎず低刺激」に振り、淡い青グラデ＋濃色文字を採用（PDFの中間ブルー背景＋白文字より、深夜モバイルの刺激が低い）。より青を強くしたい場合は調整可。
