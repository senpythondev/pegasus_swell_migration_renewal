## 4. アイキャッチ画像の状況
- **代表コラム・スタッフブログとも、全記事にアイキャッチが設定済み（各100%）で、記事ごとに固有画像**。→ サムネイル付きの投稿リスト（カード）表示がそのまま成立。生成AI画像・ストック写真が混在。
- 先の「利用者の声」（汎用ストック・顔写真なし）とは異なり、こちらは記事単位の画像。差し替えは各記事のアイキャッチで管理画面から可能。

## 5. 実装への申し送り（動的セクション）
- **スタッフブログ:** SWELL投稿リストブロックで **カテゴリ=staff（ID31/slug staff）、最新◯件、サムネイルあり** 指定＝そのまま実装可。「もっと見る」→ `/category/staff/`。
- **代表コラム:** **CPT `works`** のため、SWELL投稿リストブロックが対応しない場合は**コア「クエリーループ」ブロックで投稿タイプ=works** を指定（サムネイル＋タイトル＋日付）。「もっと見る」→ `/column/`。※実装前にSWELL投稿リストのCPT対応可否を確認。
- **在宅優先:** 在宅特化トップなら、両セクションとも**在宅記事を優先**（手動ピック、または在宅系タグ/カテゴリを新設して絞り込み）すると効果的。件数は十分（コラム6・ブログ9）。
